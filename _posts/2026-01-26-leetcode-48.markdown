# 思路
**旋转并不难找到规律，通过坐标系平移和参数方程就可以对应出来，而难点出在原地交换，即O(1)的空间复杂度。**

> 用**置换群**可以很简单的找到原地旋转的规律

由于不久前还在准备组合数学，所以看到旋转就无法不想到置换群；

下面对置换群做一些简单的讲解：

## 置换群
如期名，置换群是一种群，对于群的定义可以百度搜索一下，理解起来并不难。

而置换表示一种计算方式，可以理解成一组数之间的交换位置，即为置换，如下：

$${1，2，3，4，5} -> {5，2，3，1，4} $$ 就是一个置换。

表示的更加专业写会写成这样(1,4,5)(2)(3)——这表示1变换到4的位置，4变换到5的位置，5变换到1的位置；2变换到2的位置；3同理。

### 为什么需要置换群
在当时组合数学的学习中，置换群用来解决染色问题；考虑这样一个问题，要在一个正方形的四个点，使用两种颜色进行染色，同时正方形可以旋转，那么总共有多少种染色方法？

那么对于这个问题，就可以通过置换群和波利亚定理解决(基于置换群做理论支撑)，那具体的想法，大致是这样——考虑旋转180度的情况，一个置换可以这样写(1,3)(2,4)。
有关后续的解法，感兴趣的可以继续了解一下波利亚定理，这里不做说明。

由上可以得到，1与3是一组的，2与4是一组的，因为他们经过旋转后发生了位置互换

---
回到正文，经过上面的简单说明，其实可以发现置换的一个作用——可以进行分组划分

那么就可以进行以下考虑——每一次旋转每次只对一组做考虑，然后逐组进行操作；详细参考以下代码：

# 复杂度

- 时间复杂度: $O(n*n)$
- 空间复杂度: $O(1)$



# Code
```Java []
class Solution {
    public void rotate(int[][] matrix){
            int n = matrix.length;
            //直接算出来有几层
            int loop = (n+1)/2;
            int temp = 0, tempX = 0, tempY = 0;
            //像洋葱一样，一层一层剥开
            for(int i = 0;i < loop;i++){
                //每一圈有多少个组，那就通过每一组的第一个碰撞到他旋转后的位置结束
                for(int j = i;j<n-i-1;j++){
                    //向右逐次求取置换,一个置换是一个四元置换
                    tempX = i;
                    tempY = j;
                    temp = matrix[tempX][tempY];
                    for(int k = 0;k < 4;k++){
                        //交换要填入值和temp
                        matrix[tempY][n-tempX-1] ^= temp;
                        temp ^= matrix[tempY][n-tempX-1];
                        matrix[tempY][n-tempX-1] ^= temp;
                        //更新tempX与tempY
                        tempY = tempY ^ tempX;
                        tempX = tempX ^ tempY;
                        tempY = n - (tempX ^ tempY) - 1;
                    }
                }
            }
        }
}
```
